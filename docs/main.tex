\subsection{t-SNE and PCA}

PCA and t-SNE are used to project high-dimensional embeddings into 2D:
\begin{itemize}
    \item \textbf{PCA} preserves global variance across features.
    \item \textbf{t-SNE} preserves local neighbor distances to reveal distinct class clusters.
\end{itemize}
Separated clusters show clear features; overlapping clusters indicate class ambiguity.

\subsection{Attention Visualizations via EigenCAM}

Standard Grad-CAM struggles here for three main reasons:
\begin{itemize}
    \item \textbf{No classification head:} CLIP uses cosine similarity between image and text features rather than softmax logits.
    \item \textbf{Frozen weights:} Backpropagating through frozen layers yields weak attributions since only LoRA layers update.
    \item \textbf{Mixed precision (FP16):} Half-precision gradients often generate noisy heatmaps.
\end{itemize}

EigenCAM avoids this by being gradient-free. It computes the \textbf{first principal component} of activations at the target layer—compressing 768 feature channels into a 2D heatmap of the primary visual patterns. This reveals whether the model focuses on the walnut itself or background clutter.

\section{Zero-Shot Baseline Analysis}
% ============================================================================

Initial zero-shot testing yielded an accuracy near 19\%. Modifying the prompt templates and translating class names into descriptive English improved accuracy to 22.26\%. For example:
\begin{center}
\texttt{a photo of a brown momtaz walnut} $\quad\longrightarrow\quad$ \texttt{a photo of a premium brown walnut, a type of walnut.}
\end{center}
Despite this improvement, zero-shot accuracy remains very low and close to random guessing. CLIP's pre-training did not include fine-grained walnut cultivars, so its default embeddings cannot distinguish between these varieties without fine-tuning.

\subsubsection{Alpha 2.0 Analysis}

At $\alpha=2.0$, 4-shot performance drops to 44.3\%, but recovers at 8-shot to achieve 53.6\%.

As mentioned, finding a single configuration that consistently outperforms the baseline across all shot counts turned out to be a dead end. However, increasing $\alpha$ grants the model greater adaptation power ("wilder" parameter updates), though it also makes performance less predictable. Tuning seeds alongside these hyperparameters may yield slightly superior results in specific isolated cases.

\section{Catastrophic Forgetting \& Generalization}
% ============================================================================

Evaluating the adapted models on ImageNet validation demonstrates minimal catastrophic forgetting:
\begin{itemize}
    \item \textbf{4-Shot Model:} Achieves \textbf{66.66\%} ImageNet validation accuracy (compared to 66.71\% zero-shot CLIP, a negligible $0.05\%$ drop).
    \item \textbf{32-Shot Model:} Achieves \textbf{64.78\%} ImageNet validation accuracy (evaluation time: 176.53s, a $1.93\%$ drop).
\end{itemize}

\begin{figure}[H]
    \centering
    \begin{tikzpicture}[
        bar/.style={minimum height=0.7cm, text=white, font=\bfseries\small, anchor=west},
    ]
    \node[bar, fill=blue!60, minimum width=10cm] at (0,2) {Original Zero-Shot CLIP: \textbf{66.71\%}};
    \node[bar, fill=orange!60, minimum width=9.99cm] at (0,1) {+ 4-Shot Walnut LoRA: \textbf{66.66\%} ($\Delta = -0.05\%$)};
    \node[bar, fill=red!55, minimum width=9.71cm] at (0,0) {+ 32-Shot Walnut LoRA: \textbf{64.78\%} ($\Delta = -1.93\%$)};
    \end{tikzpicture}
    \caption{ImageNet validation accuracy across zero-shot, 4-shot, and 32-shot models.}
    \label{fig:forgetting}
\end{figure}

The forgetting is not significant. This is promising and suggests multiple fine-grained tasks can be learned sequentially without catastrophic forgetting (as discussed in the C-CLIP paper).
